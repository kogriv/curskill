## Что в живых текстах уже не совпадает с бэклогом

### BL-080. Каталога возможностей нет

Наблюдение. README называет `SKILL.md` документом команд. Сам
`SKILL.md` начинает с порядка действий агента. `automation/README.md`
называется командами стенда и перечисляет четыре файла. Шапка скрипта
ближе к списку, но она не указана из README и отстаёт от `case`.

Развитие. Один текст, на который README указывает как на описание
возможностей. В нём каждая команда стенда и каждая команда `glass.sh`,
которую скилл велит вызывать: что делает, чем кончается успех, чего не
делает. `SKILL.md` остаётся инструкцией агенту.

### BL-081. Живые тексты держат BL-067 незаписанным

Наблюдение. Бэклог: BL-067 `done`, итог 26.11.2026, около 10:31 (+07).
`agent worker start` на временную папку вышел с отказом аутентификации
и вкладку профиля стенда не создал. Вкладку `local-rc` по-прежнему
открывает handoff.

Те же сутки, уже после этого итога, три живых текста всё ещё пишут,
что замера нет:

- `skill/SKILL.md` и `skill/SKILL.ru.md`, раздел «чего скилл не берёт»:
  «Открытая работа — BL-067…BL-078. BL-067 — замер. Пока он не записан…»;
- `skill/docs/roadmap/README.md`, «Зачем стенд остаётся» и «Порядок»:
  «Пока замер BL-067 не записан», «Сначала BL-067. Пока замера нет».

Открытые строки бэклога на 12:15 (+07) — BL-074 и BL-075, плюс строки
этого аудита. BL-067…BL-073 и BL-076…BL-079 стоят `done`.

`skill/docs/README.md` статусы называет верно и при этом датирует сводку
11:10 (+07), до закрытия BL-076 в 11:47. Роадмап в разделе «Порядок»
эту сводку не догнал.

AUDIT-002 в 09:46 пишет «пока замер BL-067 не записан». Это время
самого аудита, до замера. Его текст не переписывается задним числом.

Развитие. Живые тексты называют итог BL-067, а не ожидание замера.
Открытая работа в скилле — те номера, которые в бэклоге не `done`.

### BL-082. Шапка скрипта и описание для выбора скилла отстают от команд

Наблюдение. Шапка `cursor-stand.sh` не содержит `mcp ready`. Строка про
MCP говорит «тоггл источника ON (проектный/user)» так, будто оба файла
одинаково доходят до вкладки. Замер BL-076: файл папки видит окно,
вкладка видит пользовательский `~/.cursor/mcp.json`, если воркер
стартовал после записи. Шапка ссылается на `INVENTORY.md`. Файла с
таким именем в репозитории нет. Строка «Handoff 3.23» называет текущий
порядок кликов версией, на которой его снимали раньше.

Описание в шапке `SKILL.md` и `SKILL.ru.md`, поле `description`, тоже
говорит «On Cursor 3.23» и «enabling project MCP». В списке команд
описания нет `discard`, `inventory`, `archive`, `focus`, `workers`,
`mcp ready`. Это текст, по которому сессия решает, брать ли скилл.

Тело скилла после коммита `6ee94f6` путь MCP уже различает: файл папки
для окна, пользовательский файл для вкладки, проверка `mcp ready`.
Шапка и описание это не подхватили.

Развитие. Шапка скрипта перечисляет те же команды, что `case`, включая
`mcp ready`, и не обещает, что файл папки виден вкладке. `INVENTORY.md`
не упоминается, пока файла нет. `description` не называет проектный MCP
путём до вкладки.

### BL-083. Заголовки «на 3.23» стоят рядом с замером 3.30.14

Наблюдение. Пакет стенда 26.11.2026 — Cursor 3.30.14. Доктор в тот же
день напечатал предупреждение «якоря калиброваны на 3.23, пакет
3.30.14» и подтверждение «якоря проверены для 3.30.14». Дефолт
`CURSOR_STAND_UI_CALIBRATED=3.23` в таблице Env — эта справка. Её
менять этим аудитом не нужно: доктор как раз сравнивает её с пакетом.

Рядом заголовки говорят о 3.23 как о текущем способе:

- `SKILL.md` / `SKILL.ru.md`: «Как получается local-rc на 3.23», «на
  3.23 слэш сам стартует Environment»;
- `reference.md` / `reference.ru.md`: раздел «Ловушка 3.23» и таблица
  «Якоря UI … пакет 3.23.23»;
- тело того же скилла двумя абзацами выше: «Пакет, на котором сняты
  якоря: 3.30 (раньше 3.23)».

Живые handoff 26.11.2026 на этом пакете доходили до `local-rc`. Это
записано в итогах BL-071 и BL-078. Заголовок «на 3.23» этого не
говорит.

Развитие. Заголовок отличает «так снимали на 3.23» от «так handoff
прошёл на 3.30.14 26.11.2026». Дефолт `CURSOR_STAND_UI_CALIBRATED`
остаётся `3.23`, пока его отдельно не поднимут.
