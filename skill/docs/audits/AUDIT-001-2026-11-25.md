## BL-047. Root-обёртка Xorg пишет в /tmp

Уровень: critical. Класс: уязвимость.
`automation/curskill-xorg:33`.

Факт. Скрипт рассчитан на запуск через sudo и сам стартует
`/usr/bin/Xorg`. Конфиг и каталог зашиты так:

```
RUNTIME_CONF="/tmp/curskill-xorg-nvidia-headless.conf"
EMPTY_DIR="/tmp/xorg-empty-confdir"
```

Запись конфига — перенаправление оболочки в `$RUNTIME_CONF` (`:61`).
`mkdir -p "$EMPTY_DIR"` (`:71`) не заменяет уже существующий каталог.
Третий аргумент, тег, попадает в путь лога без проверки:

```
-logfile "/tmp/xorg-${TAG}.log"
```

(`:76`). Белый список номера дисплея при этом есть (`:16`).

Догадка. Заранее созданная ссылка на месте конфига уводит запись root
в другой файл. Свой каталог в `/tmp/xorg-empty-confdir` Xorg прочитает
как `-configdir`. Тег с `..` уводит лог из `/tmp`.

## BL-048. Лог xdg-open хранит URL целиком

Уровень: high. Класс: уязвимость.
`automation/cursor-stand.sh:230`.

Факт. `write_xdg_open` генерирует скрипт, первая строка которого:

ставится в `0700` (`:256`, `:379`).

Догадка. Чужой пользователь файл не прочитает. Тот, кто смотрит логи
стенда, уносит код логина из URL.

## BL-050. Archive берёт первое слово на кадре

Уровень: high. Класс: уязвимость.
`automation/glass_agents.py:1804`.

Факт. `archive-pos` собирает все слова `archive` и отбрасывает только те,
у которых на соседней строке по Y есть `below`. Ограничения по X нет.

В якорях есть `archive-item` с зоной `(100, 600, 280, 750)` (`:322`).
`archive-pos` эту зону не использует.

Догадка. Если OCR не увидел `below`, подходит слово Archive из пункта
Archive All Below. Слово archive в тексте чата тоже становится кликом.

## BL-054. Новый проектный mcp.json создаётся 0644

Уровень: medium. Класс: уязвимость.
`automation/glass_agents.py:965`.

Факт. Если файл уже есть, сохраняется его mode. Если путь —
`~/.cursor/mcp.json`, mode `0o600`. Иначе новый файл получает `0o644`.
Временная запись идёт через `_atomic_write` с этим mode.

Догадка. Проектный `mcp.json` с токеном читается другими пользователями
машины. Домашний файл этим путём не ослабляется.

## BL-056. Патч лаунчера молча выбрасывает ключ из argv

## BL-057. Пустой список защиты archive никого не держит

Уровень: medium. Класс: дефект.
`automation/cursor-stand.sh:1874`.

Уровень: medium. Класс: дефект.

Догадка. Короткое имя или случайные пять букв в OCR подтверждают чужую

## BL-061. Разбор прокси режет URL по первому двоеточию

Уровень: medium. Класс: дефект.
`automation/cursor-stand.sh:384`.

Факт. Хост получается так: срезать схему `^[a-z]+://`, затем всё от
первого `:`. Порт — всё после последнего `:`. Проверка «порт слушает»
выполняется только если хост равен `127.0.0.1` или `localhost` (`:386`).

Для `http://user:pass@127.0.0.1:10816` первое двоеточие стоит в userinfo.
Хост после среза — `user`, не `127.0.0.1`, и проверка порта не
выполняется.
