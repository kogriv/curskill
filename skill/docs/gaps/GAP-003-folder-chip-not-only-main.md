# GAP-003. Чип папки узнаётся только по слову main

Статус: закрыт [BL-045](../backlog/README.md).

## Факты

Якорь `folder-chip` искал токен `main` в зоне 700,450–1100,520 и кликал
на 55 px левее его центра. Так чип выглядел, когда внутри него была
ветка.

25.11.2026, k-99, 15:57 (+07). `handoff -w /tmp/curskill-full-20261125
-n full-cycle` после New Chat: «handoff ЗАБЛОКИРОВАН: не найден якорь
folder-chip». Снимок `var/shots/handoff-fail-155702.png`. OCR этой
полосы:

- `curskill-cycle-20261125` в 800,482, 137×13
- `This` в 984,473, `Computer` в 1017,473
- слова `main` нет
- `find_anchor(..., "folder-chip")` до правки возвращал пусто
- `env-this-computer` на том же снимке находился: 1028,487
- `plan-idea` находился: 870,549

Имя на чипе — папка предыдущего оборванного handoff
(`/tmp/curskill-cycle-20261125`, черновик «Ready response» без записи в
sqlite). Новый чат открылся уже с этим чипом, не с веткой `main`.

В тот же день более ранние handoff находили `folder-chip` около
864,491: чип тогда содержал `main`.

## Догадка

Пустой новый чат показывает ветку `main`. Если предыдущий чат уже
выбрал папку, следующий New Chat оставляет её имя на чипе. Оба вида —
один и тот же чип слева от This Computer.

## Не это

Координаты с голоса. Клик по сайдбару «Ready response». Повтор handoff
без смены якоря: слово `main` на этом снимке не появится.

## Проверка

25.11.2026, 20:03 (+07). Handoff в `/tmp/curskill-pass-20261125` на том же
экране, где чип уже носил имя папки: `folder-chip 868,488`,
`folder-result 840,556`. Это центры имени слева от This Computer, не
клик по слову `main`. Дальше папка выбралась, сессия стала local-rc.
