# Документы развития curskill

Агенту при обычной работе со стендом они не нужны. Читать, когда меняешь
скилл или `automation/cursor-stand.sh`.

| папка | что | правило |
|---|---|---|
| [gaps/](gaps/) | что наблюдалось, с фактами отдельно от догадок | один файл на разрыв, `GAP-NNN-…md` |
| [design/](design/) | как этот разрыв закрываем | `DESIGN-NNN-…md`, ссылка на GAP |
| [backlog/](backlog/) | задачи с приёмкой | таблица в `README.md`; статус менять там же |
| [roadmap/](roadmap/) | общий порядок развития и то, что скилл на себя не берёт | `README.md`; открытые пункты совпадают со строками бэклога |
| [audits/](audits/) | разбор кода целиком или разбор направлений развития | `AUDIT-NNN-….md`; каждый пункт — строка бэклога |

Нумерация продолжает бэклог репозитория `cursor-stand` (там закрыты
BL-001…BL-042). Новые задачи этого репозитория начинаются с BL-043.
Роадмап 26.11.2026 завёл BL-067…BL-079. На 26.11.2026, 11:10 (+07)
закрыты BL-067…BL-073, BL-077 и BL-078. BL-076 остаётся открытым:
панель видит инструмент, вкладка local-rc отвечает MCP-MISSING.
BL-074 ждёт свободный запуск стенда, BL-075 — другую машину.
Открытые номера не начинать, пока человек не попросил конкретный номер.
